# Chdaliu Tap

## How do I install these formulae?

`brew install chdaliu/tap/<formula>`

Or `brew tap chdaliu/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "chdaliu/tap"
brew "<formula>"
```
